Technical specifications
Negatives
30 color negative films: Kodak 20, Fujifilm 9, Agfa 1
Reversal
Fujichrome Velvia 50, Velvia 100, Provia 100F, Astia 100F, and Kodak Ektachrome E100, viewed on a light table
Print
18 photographic papers and cinema print stocks, such as Kodak Endura Premier, Vision 2383, and Fuji Crystal Archive; Cine Look (Kodak Vision 2383) as a separate option; Rec. 709 SDR output
Negative Scan
A virtual scanner reads and inverts the negative; OpenDRT forms SDR or HDR output; scan exposure, contrast, cyan, magenta, yellow, and black; Neutral auto color at 50% by default
Scene Light
Defaults to As Shot and follows the temperature and tint of the RAW white balance
Film format
16mm, 35mm, or 70mm; sets the grain size relative to the frame; smaller formats enlarge light spread and halation
Grain
Formed in the film layers before printing or scanning, with the granularity data of the stock; strength 0–200%; the scale stays the same as you zoom
GPU
CUDA, OpenCL, and Metal; the film data is included in the installer
Command line
film.list in alcedo-cli lists the stocks for scripted editing and rendering
Data
Digitized datasheets of spectral_film_lut; the Astia 100F profile of fotufilm (CC BY-SA 4.0)

New in 0.3.4

AI Masks, search, and more

AI Masks and range masks, an AI Models settings page, a search palette, and LUT previews on your photo.

Full release notes

  • AI Masks

    Select the subject, background, sky, or people, or any object with points, a drawn path, or a box. The tool has its own Undo and Redo; Confirm saves the result as one history step.

  • Luminance/Hue Range

    Restrict any mask by brightness and hue, with two-handle bars, numeric fields, softness, and a saturation threshold.

  • AI Models settings

    Download and manage the AI Mask models and the CLIP search models on one page. Each card shows the license, size, and progress. Models load on demand.

  • Search palette

    Recent searches, commands, filters, and photo previews in one window. Enter applies the search to the Library.

  • Color wheels

    Lift, Gamma, and Gain adjust shadows, midtones, and highlights separately; the new Offset wheel shifts all tones. Master values use EV.

  • Library cards

    Photo cards show edit marks and star ratings; on larger cards, click a star to rate. The filmstrip follows Library filters.

Command line

AI agents

alcedo-cli installs with Alcedo Studio and gives an agent the commands behind the interface: open, import, rate, edit, preview, search, and export.

The Alcedo skill for agents
Technical specifications
Command line
alcedo-cli, installed next to the application (inside the app bundle on macOS); JSON in and out
Agents
Claude Code, Codex, and other agents that run shell commands; the Alcedo skill teaches them the commands
Commands
Projects, import, rating, every editor field, LUTs, Film Print stocks, versions, previews, search, and export
Sessions
Headless, without a window, for batch work; or the window you are using
Control
Your edit controls are locked while an agent works; pan, zoom, and scopes stay available; Stop ends its control at once
History
Agent edits are marked and show the agent's note; undo works as for your own edits

Every grade node has its own adjustments and masks. Local adjustments stay inside their masks.

Technical specifications

Develop → Color Grade nodes (any number) → Display Transform
Grading tools
Tone · local tone mapping · Lift / Gamma / Gain and Offset color wheels · tone curve · selective color · detail
Node editing
Add, connect, rename, multi-select, batch delete; recorded in history and versions
Lock protection
Default grade layers are locked; any layer can be locked by hand
Mask types
Linear gradient · radial gradient · AI Mask
AI Masks New
Subject, Background, Sky, People; or points, a drawn path, or a box. Add and subtract, include or exclude individual people, Feather and Expand; models run on your device; saved masks render without the models
Range New
Luminance and hue range for any mask, with softness and a saturation threshold; Show selection displays the coverage
Mask controls
Position, radius, rotation, inner and outer feather, opacity, invert
Masks per node
Multiple, organized in the mask groups panel with thumbnails

Scene-referred color

32-bit floating point throughout, graded in ACEScc log space for an even response to exposure and tone.

Technical specifications
Precision
32-bit floating point throughout
Camera color
Camera color matrices; spectral data from rawtoaces-data for some models
Grading space
ACEScc (AP1 primaries)
Display transform
ACES 2.0 · OpenDRT · Film Print
Output targets
Rec.709 · Display P3 · Rec.2020, with PQ and HLG
HDR monitoring
Extended dynamic range (EDR) on macOS
Contrast
S-curve on OkLab lightness; brightness and hue are preserved
LUT encodings
50 scene and display encodings for each LUT's input and output; a display output returns to the scene through the ACES 2.0 inverse output transform
JPEG, PNG, TIFF, OpenEXR
The embedded color profile brings the image into ACES; OpenEXR, PQ, and HLG images are marked as HDR

Render engine

A render graph on the GPU. RAW decoding and geometry are cached; Color Grade nodes run again on every change.

Technical specifications
Windows
CUDA (NVIDIA) · OpenCL (AMD / Intel)
macOS
Metal (Apple Silicon)
Caching
The RAW decode and geometry results are cached by revision and reused; Color Grade nodes are not cached and run again on every change
Working memory
Color Grade nodes use two RGBA32F buffers in turn; memory does not grow with the number of nodes
Transient memory
Demosaicing, highlight reconstruction, and local tone mapping share one pool, released when rendering finishes
One pipeline
Editor preview, thumbnails, analysis, and export; thumbnails and export use their own GPU resources and never slow the preview
Preview
2560 px long edge while dragging, 4096 px at rest; only the visible region when zoomed
Scopes
Histogram · RGB waveform, with filled channels and clipping markers

Library and search

Built on the DuckDB embedded database. All search runs on your own machine.

Technical specifications
Project file
One .alcd file: folders, metadata, semantic indexes, edit history; databases over 2 GiB open, and saves stream the database
Search speed
20,000 photos: live preview in about 12 ms, applied search in 13–21 ms, on a background thread
Search palette New
Recent searches, commands, filters, and photo previews in one window; Enter applies the search to the Library
Search terms
“6.7” means June 7; “iso800” does not match ISO 8000; “dng” is a file type; terms combine with AND
Metadata filters
Any combination of camera, lens, aperture, shutter, ISO, date, and rating
Semantic search
Local multilingual CLIP models and an HNSW vector index; download and activate them in Settings > AI Models
Collections New
Nested collections in a compact tree: create and rename in place, drag to move, photo counts
Photo cards New
Edit marks and star ratings; click a star on larger cards to rate
Shooting heatmap
A year of shooting activity; click a day to filter
Import
RAW, JPEG, PNG, TIFF, and OpenEXR, chosen by type for each folder and recognized by content
Sort and group
By any field, import day, or last edit; groups collapse and expand

Post Processing
