0.3.3 新增

AI Agent

alcedo-cli 随 Alcedo Studio 一起安装，把界面背后的命令交给 Agent：打开、导入、评分、修图、预览、搜索与导出。

Agent 用的 Alcedo skill
技术规格
命令行
alcedo-cli，安装在应用旁边（macOS 上位于应用包内）；输入与输出均为 JSON
Agent
Claude Code、Codex 等能运行命令行的 Agent；Alcedo skill 教会它们使用这些命令
命令
项目、导入、评分、所有编辑参数、LUT、版本、预览、搜索与导出
会话
不开窗口的后台会话，适合批量处理；或你正在使用的窗口
控制权
Agent 操作期间编辑控件锁定，仍可平移、缩放和查看示波器；“停止”立即收回控制权
历史记录
标出 Agent 所做的编辑并显示它的备注；撤销与你自己的编辑一样有效

新功能

0.3 的更多新功能

收录 113 卷胶片的 LUT 浏览器、JPEG 与 TIFF 编辑、前后对比、导出预设，RAW 导入提速近 30 倍。

完整发布说明

LUT 浏览器

按类别、来源、品牌和印放胶片筛选。点一下套用，再点一下移除。

LUT 编码

为 LUT 选择输入和输出编码，从相机 Log 到 PQ，并为这个 LUT 记住。

黑柔滤镜

明亮光源泛起柔和光晕，中间调依然清晰。

前后对比

比较修改前后或两个版本：并排显示，或拖动分割线。

JPEG、TIFF 与 EXR

像 RAW 一样编辑。读取内嵌色彩配置文件，转换到 ACES。

排序与分组

按相机、镜头或任意字段给图库分组，分组可以折叠。

节点与蒙版

每个调色节点都是一套完整的工具，局部调整只作用于蒙版范围之内。

技术规格
节点结构
Develop → Color Grade 节点（数量不限）→ 显示渲染变换
调色工具
局部色调映射 · 三路色轮（Lift / Gamma / Gain）· 色调曲线 · 选择性色彩
节点编辑
新增、连线、重命名、多选、批量删除；记入历史与版本
删除保护
默认调色层自动上锁，任意图层均可手动上锁
蒙版类型
线性渐变 · 径向渐变
蒙版参数
位置、半径、旋转、内外羽化、不透明度、反转
蒙版数量
每个节点可叠加多个，在蒙版组面板中按层管理并显示缩略图

场景参考色彩

全程 32 位浮点，在 ACEScc 对数空间中调色，曝光与影调的响应均匀。

技术规格
数值精度
全程 32 位浮点
相机色彩
相机色彩矩阵；部分机型为 rawtoaces-data 光谱数据
调色空间
ACEScc（AP1 原色）
显示渲染变换
ACES 2.0 · OpenDRT
输出目标
Rec.709 · Display P3 · Rec.2020，含 PQ 与 HLG
HDR 监看
macOS 扩展动态范围（EDR）
对比度
作用于 OkLab 亮度的 S 曲线，不改变整体亮度，也不偏色
LUT 编码 新
26 种场景与显示编码，用于 LUT 的输入和输出；显示编码输出经 ACES 2.0 逆向输出变换转回场景
JPEG、PNG、TIFF、OpenEXR 新
读取内嵌色彩配置文件，转换到 ACES；OpenEXR 以及 PQ 或 HLG 图像标记为 HDR

渲染引擎

GPU 上的渲染图：调整参数时，只重算其后的节点。

技术规格
Windows
CUDA（NVIDIA）· OpenCL（AMD / Intel）
macOS
Metal（Apple Silicon）
增量渲染
未改动节点的结果按版本号缓存并直接复用
工作显存
两块 RGBA32F 缓冲交替读写，显存不随节点数量增长
瞬态显存
去马赛克、高光重建与局部色调映射共用同一内存池，渲染结束即释放
同一条管线
编辑预览、缩略图、分析与导出；缩略图和导出使用独立的 GPU 资源，不拖慢预览
预览
拖动时长边 2560 像素，静止时 4096 像素；放大时仅渲染可见区域
示波器
直方图 · RGB 波形图

图库与检索

基于 DuckDB 嵌入式数据库，检索全部在本机进行。

技术规格
工程文件
单一 .alcd 文件：目录、元数据、语义索引、编辑历史
搜索速度
两万张图库：输入即预览约 12 毫秒，应用搜索 13–21 毫秒，在后台线程运行
搜索词
“6.7”识别为 6 月 7 日；“iso800”不再匹配 ISO 8000；“dng”识别为文件类型；多个词同时满足
拍摄热力图
全年拍摄活跃度，点击某天即可筛选
元数据筛选
相机、镜头、光圈、快门、ISO、日期、评分的任意组合
语义检索
本地 CLIP 模型与 HNSW 向量索引；模型首次下载后完全离线
导入 新
RAW、JPEG、PNG、TIFF 与 OpenEXR，每个文件夹可按类型选择，按文件内容识别；导入失败不留残余记录
导入速度 新
639 张 RAW 照片 1.1 秒导入完成（此前 31.6 秒），峰值内存 149 MB
排序与分组 新
按任意字段、导入日期或最后编辑时间；分组可折叠和展开

胶片与风格

113 卷由光谱模型生成的胶片，一个能浏览你所有 LUT 的浏览器，以及在预览和导出中完全一致的后期效果。

技术规格
胶片 LUT
113 卷，分属官方 Spectral Film LUT 与 spektrafilm 两个 LUT 包；在“设置 > LUT”中下载，安装前校验签名
LUT 浏览器 新
网格或列表；按类别、来源、品牌和印放胶片筛选；搜索可容忍拼写错误；强度 0–100%
自己的 LUT 新
LUT 库任意文件夹中的 .cube 文件，归入“用户”类别
颗粒
基于 IPOL 2017《Realistic Film Grain Rendering》，强弱随画面明度变化
光晕
高反差边缘周围的微红散射（Halation）
黑柔滤镜 新
明亮光源泛起柔和光晕，中间调细节保持清晰
后期处理 新
清晰度、锐化、颗粒、光晕与黑柔滤镜集中在同一页

导出

最高 32 位浮点，支持带增益图的 HDR，每种用途都有现成的预设。

技术规格
预设 新
标准、网页、社交媒体、电子邮件、最高质量 JPEG、16 位 TIFF、EXR 存档，也可以保存自己的预设
格式
JPEG 8 位 · PNG 8/16 位 · TIFF 8/16/32 位 · OpenEXR 16/32 位浮点 · Ultra HDR
尺寸
原始尺寸 · 长边 · 边界框 · 打印尺寸与 DPI
文件名变量
源文件名、日期、相机、镜头、光圈、快门、ISO、评分、序号
元数据 新
EXIF 元数据与 ICC 配置文件可分别开关；相机和镜头序列号从不写入
导出位置 新
记住上次的导出文件夹，重启后依然有效

以及坚实的基础。

RAW 解码

技术规格

Canon、Nikon、Sony、Fujifilm、Panasonic、OM System、Leica、Pentax、Sigma，以及手机与无人机的 DNG

历史与版本

每次调整都是一条提交记录，回溯后的新改动不会覆盖历史。

技术规格
命名版本
同一张照片的多个版本，各自为独立的历史分支
前后对比 新
比较修改前后或两个版本；并排或分割线，左右或上下布局
按需复制 新
版本、节点乃至单项参数，现在也包括 RAW 解码、白平衡、镜头校正与裁剪；粘贴到多张照片时在后台运行
快捷键
可自定义，带冲突检查
